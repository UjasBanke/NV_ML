# NV_ML

Machine-learning framework developed for NV-center-based quantum navigation simulations.

## Objectives

- Generate synthetic datasets.
- Train machine-learning models.
- Predict position coordinates.
- Evaluate model performance.
- Export results.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- XGBoost
